Review — Bug Fix: Solo & Multiplayer Game Not Starting
====================================================

Root Cause:
-----------
renderLobbyContent() ใน lobby-screen.ts ถูกเรียกหลายครั้งตอน init 
(ครั้งแรก line 422 ก่อน init() + ครั้งที่สอง line 324 หลัง init สำหรับ solo)

แต่ละครั้ง register event listener ผ่าน setTimeout(() => {...}, 0)
ผลคือ btn-start-game มี click handler ซ้ำกัน 2+ ชุด

เมื่อ user กด "เริ่มเกม":
  Handler 1: startGame() → navigate('/game') → DOM ถูกเปลี่ยนเป็น game screen ✅
  Handler 2: อ่าน config จาก DOM → แต่ select element ไม่มีแล้ว (DOM ถูกเปลี่ยน)
    → questionCount = undefined → parseInt(undefined) = NaN
    → generateQuestions(pool, NaN) → slice(0, NaN) → return []
    → _questions = [] → currentQuestion = null
    → navigate('/game') → route guard เจอ currentQuestion === null
    → redirect ไป /main 💥

เรื่องเดียวกันนี้ทำให้ Multiplayer lobby มีปัญหา player ซ้ำ
เพราะ event listener ซ้ำกันหลายชุด

Fixes Applied:
--------------
1. lobby-screen.ts: เพิ่ม renderGeneration counter
   - แต่ละ renderLobbyContent() increment counter
   - setTimeout callback เช็ค generation ก่อน register listeners
   - ถ้า generation ไม่ตรง (มี render ใหม่กว่า) → skip ไม่ register
   
2. lobby-screen.ts: เพิ่ม startedGame flag
   - กัน double-fire ของ start button
   - reset เมื่อ error เพื่อให้ retry ได้

3. lobby-screen.ts: parseInt fallback
   - questionCount === 'all' ? 'all' : (parseInt(questionCount) || 10)
   - กัน NaN จาก undefined DOM reads

4. game-controller.ts: เพิ่ม phase guard ใน startGame()
   - ถ้า phase !== 'LOBBY' → ignore (ป้องกัน double-start)

5. shuffle.ts: เพิ่ม NaN guard ใน generateQuestions()
   - ถ้า count เป็น NaN/invalid → fallback ใช้ pool ทั้งหมด
   - Math.max(1, ...) guarantee อย่างน้อย 1 question

6. lobby-screen.ts: PLAYER_LIST handler
   - เปลี่ยน gameController.destroy() → gameController.resetToLobby()
   - destroy() จะ wipe config/callbacks ด้วย ซึ่งไม่ถูกต้อง

7. game-controller.ts: resetToLobby() ปรับปรุง
   - เพิ่ม _answerTimes.clear() + _players.clear()
   - เพิ่ม clearPlayers() method ใหม่

Test Results:
-------------
- Solo mode: เล่นได้ ไม่ redirect กลับ /main ✅
- Question progression: 1/10 → 2/10 → ... ✅
- TypeScript compilation: clean ✅
