1. ภาพรวมของโปรเจกต์ (PROJECT OVERVIEW)
--------------------------------------------------------------------------------
GuessThe? คือเว็บแอปพลิเคชันเกมแข่งขัน "ทายเพลง & ทาย MV" แบบ Real-Time Interactive 
สร้างด้วย Vite + TypeScript + Tailwind CSS v4 / Custom CSS
รองรับทั้ง:
  1. โหมดเล่นคนเดียว (Singleplayer / Solo)
  2. โหมดผู้เล่นหลายคนแบบออนไลน์ (Online Multiplayer รองรับได้ถึง 10 คน) ผ่าน WebRTC P2P (PeerJS) 
     โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ฐานข้อมูลส่วนกลาง Host ทำหน้าที่เป็น Game Server แบบกระจายศูนย์
  3. ระบบ Media แบบ Hybrid (HTML5 Media <video> ร่วมกับ YouTube IFrame Fallback)
  4. ระบบป้องกันการสปอยล์ระดับสมบูรณ์แบบ 100% (Anti-Spoiler Mask & Pitch-black Countdown)
  5. ระบบกระดานคะแนนคั่นระหว่างข้อแบบแอนิเมชันลื่นไหล (Intermediate Leaderboard with FLIP Animation)
  6. ระบบ CI/CD GitHub Actions อัตโนมัติ (Push ขึ้น main แล้วเว็บอัปเดตทันที)

【 หน้า 2: จัดการคลังเพลง (TRACK EDITOR SCREEN) — Route: #/editor 】
================================================================================
จุดประสงค์: เพิ่ม ลบ แก้ไข ฟังตัวอย่างคลิป ปักหมุดวินาที และนำเข้า/ส่งออกเพลง
● เมนูและปุ่มควบคุม:
  [ปุ่ม 1] "←" (ปุ่มย้อนกลับ): กลับสู่หน้าหลัก
  [กล่อง 2] ฟอร์มเพิ่มเพลง / แก้ไขเพลง (Track Form):
    - ช่อง "YouTube ID หรือ ลิงก์คลิป" (Input ID: input-youtube-id):
      รองรับ URL เต็ม (youtube.com/watch?v=...), ลิงก์ย่อ (youtu.be), Shorts, หรือ ID 11 หลัก
    - ปุ่ม "🔍 โหลดคลิป & ชื่อเพลง" (Button ID: btn-fetch-title):
      ดึงชื่อเพลงและศิลปินอัตโนมัติผ่าน YouTube oEmbed พร้อมเปิดจอวิดีโอ Preview ขึ้นมาทันที
    - หน้าต่าง "📺 ตัวอย่างคลิป (Preview Player)":
      วิดีโอพรีวิวแบบโต้ตอบได้ มีไทม์ไลน์ให้เลื่อนหาวินาทีที่ต้องการ
      - ปุ่ม "📍 ตั้งเริ่มทาย (Xs)": กดเพื่อดึงวินาทีปัจจุบันของคลิปมาใส่ช่องวินาทีเริ่มทาย
      - ปุ่ม "📍 ตั้งเริ่มเฉลย (Xs)": กดเพื่อดึงวินาทีปัจจุบันของคลิปมาใส่ช่องวินาทีเริ่มเฉลย
    - ช่อง "ชื่อเพลง" (Input ID: input-title): ดึงชื่อเพลงมาให้ สามารถแก้ไขพิมพ์ข้อความเองได้
    - ช่อง "เริ่มที่วินาที (ฟังตอนทาย)" + ปุ่ม "▶️ ฟัง":
      กำหนดวินาทีท่อนที่จะให้ผู้เล่นฟังตอนทาย สามารถกดปุ่ม "▶️ ฟัง" เพื่อทดสอบเล่นคลิปจากวินาทีนั้นได้ทันที
    - ช่อง "เริ่มที่วินาที (ตอนเฉลย)" + ปุ่ม "▶️ ฟัง":
      (ใส่หรือไม่ใส่ก็ได้) กำหนดวินาทีท่อนฮุคที่จะเปิดเฉลยตอนหมดเวลา ถ้าไม่ใส่จะใช้วินาทีทาย
    - กล่องเลือก "ประเภท": เลือกว่าเป็น '🎬 MV Video' (ดูคลิปภาพ) หรือ '🎵 Audio Only' (ฟังแต่เสียง)
    - กล่องเลือก "คะแนน": 10, 15, 20, 25, 30 แต้ม
    - ปุ่ม "➕ เพิ่มเพลง" / "💾 บันทึกการแก้ไข" (Button ID: btn-add-track): บันทึกข้อมูลลง LocalStorage
    - ปุ่ม "✕ ยกเลิกการแก้ไข" (Button ID: btn-cancel-edit): สลับออกจากโหมดแก้ไขกลับเป็นโหมดเพิ่มใหม่
  [แถบ 3] เครื่องมือจัดการชุดข้อมูล (Toolbar):
    - ปุ่ม "นำเข้าไฟล์" (File Input ID: input-import-json): เลือกไฟล์ .json จากเครื่องเข้าคลัง
    - ปุ่ม "วางโค้ด" (Button ID: btn-open-paste-modal): เปิด Pop-up ให้วางข้อความ JSON
    - ปุ่ม "Export" (Button ID: btn-export-json): ดาวน์โหลดไฟล์ JSON และเปิด Pop-up ให้คัดลอกโค้ด
    - ปุ่ม "โหลดเพลงตัวอย่าง" (Button ID: btn-load-samples): โหลดเพลงฮิต 10 เพลงที่มีการตั้งวินาทีทายและเฉลยไว้ล่วงหน้า
  [แถบ 4] ปุ่มปรับประเภทแบบเหมาทั้งหมด (Batch Actions):
    - ปุ่ม "ทาย MV ทั้งหมด": เปลี่ยนทุกเพลงในคลังเป็นโหมดดูคลิป MV พร้อมกันในคลิกเดียว
    - ปุ่ม "ทายเพลงทั้งหมด": เปลี่ยนทุกเพลงในคลังเป็นโหมดฟังเสียง (Audio Only) พร้อมกันในคลิกเดียว
  [แถบ 5] "🗑️ ลบเพลงทั้งหมด" (Button ID: btn-clear-all): มีระบบยืนยันป้องกันการกดผิดพลาด
  [แถบ 6] รายการเพลงทั้งหมด (Track List): แต่ละเพลงมีปุ่ม พรีวิว (▶️), แก้ไข (✏️), ลบ (🗑️)

================================================================================
จุดประสงค์: เตรียมความพร้อมของผู้เล่น และตั้งค่ากฎกติกาการแข่งขัน
● เมนูและกล่องข้อมูล:
  1. ปุ่ม "← กลับหน้าหลัก": ตัดการเชื่อมต่อและกลับสู่หน้าแรก
  2. กล่องแสดงรหัสห้อง (สำหรับ Host): แสดงรหัส 5 หลักขนาดใหญ่ แตะหรือคลิกเพื่อคัดลอกได้ทันที
  3. รายชื่อผู้เล่นในห้อง (Players Grid):
     - รองรับผู้เล่น 1 ถึง 10 คน
     - แสดงชื่อ, Avatar ประจำตัว, ป้าย "👑 Host", และสถานะ "● Online"
     - มีระบบป้องกันชื่อซ้ำและตัดการเชื่อมต่อของผู้เล่นผี (Zombie Peers) อัตโนมัติ
  4. แผงตั้งค่าเกม (⚙️ ตั้งค่าเกม — ปรับได้เฉพาะ Host และ Solo):
     - "จำนวนข้อ": เลือก 'ทั้งหมด', 5 ข้อ, 10 ข้อ, 15 ข้อ, 20 ข้อ
     - "เวลาแสดงเพลงทาย": 1s, 2s, 3s (มาตรฐาน), 5s, 8s, 10s (ระยะเวลาคลิปท่อนเพลง)
     - "เวลาจับเวลาตอบ": 5s, 10s (มาตรฐาน), 15s, 20s, 30s (เวลานับถอยหลังกดช้อยส์)
     - "เวลาแสดงตอนเฉลย": 3s, 5s (มาตรฐาน), 7s, 10s, 15s (ระยะเวลาเปิดเฉลยให้ฟังท่อนฮุค)

● ปุ่มในหน้า Lobby:
  [ปุ่ม 1] "🎮 เริ่มเกม!" (Button ID: btn-start-game):
    - สำหรับ Host/Solo: สุ่มเพลงและช้อยส์ แล้วส่งแพ็กเก็ตเริ่มเกมไปยังลูกห้องทุกคน
    - สำหรับ Client: แสดงสถานะ "รอ Host เริ่มเกม..."

【 หน้า 4: หน้าเล่นเกม (GAME SCREEN) — Route: #/game 】
================================================================================
จุดประสงค์: หน้าจอหลักขณะกำลังเล่นเกม ทายเพลง ดูเฉลย และตารางคะแนนคั่นข้อ
● ขั้นตอนการเล่นเกมอย่างละเอียด (Game Lifecycle Flow):

  ขั้นที่ 0: หน้าเตรียมความพร้อมรวม (Initial Buffering Screen & Hard Timeout 10s)
    - แสดง Overlay มืด พร้อมแสดงสถานะการโหลดเพลงของผู้เล่นทุกคน (Grid พร้อม/กำลังโหลด)
    - โหลดสตรีมเพลงข้อแรกเข้าหน่วยความจำ เพื่อให้เล่นพร้อมกันอย่างไม่มีใครได้เปรียบ
    - ระบบ Hard Timeout 10 วินาที: หากมีผู้เล่นเน็ตช้าเกิน 10 วินาที Host จะมีปุ่ม
      "⚠️ บังคับเริ่มเกมทันที (Force Start)" ปรากฏขึ้นมาให้กดข้ามเพื่อเริ่มเกมได้เลย

  ขั้นที่ 1: นับถอยหลังเตรียมตัว 3.. 2.. 1.. (Pitch-Black Countdown)
    - หน้าจอแสดงเลขนับถอยหลัง 3.. 2.. 1.. แบบ Pulse Animation ขนาดใหญ่
    - พื้นหลังทึบสนิท 100% (Solid Black) เพื่อป้องกันไม่ให้เห็นภาพคลิปหลุดออกมาก่อนเวลา

  ขั้นที่ 2: ช่วงเล่นท่อนเพลงทาย (Snippet Playing Phase)
    - เครื่องเล่นเล่นท่อนเพลงตามเวลาที่ตั้งไว้ (เช่น 3 วินาที)
    - ด้านบนมีแถบ "Anti-Spoiler Header Mask" บังหัววิดีโอ 100% ปิดชื่อคลิปและชื่อช่องมิดชิด
    - โหมด MV Video: เปิดให้เห็นคลิปภาพเคลื่อนไหว
    - โหมด Audio Only: มีม่านดำและอนิเมชัน Audio Visualizer บังภาพไว้ ได้ยินเฉพาะเสียง
    - **สำคัญ**: ปุ่มช้อยส์ทั้ง 4 ข้อถูกล็อค (Disabled & Opacity 60%) เพื่อไม่ให้กดมั่วก่อนฟังจบ

  ขั้นที่ 3: ช่วงจับเวลาตอบ (Answering Phase)
    - จอวิดีโอจะถูกคลุมม่านดำทันที เพื่อกันภาพสปอยล์
    - ปุ่มช้อยส์ 4 ข้อ (A, B, C, D) ปลดล็อคพร้อมกัน ให้ผู้เล่นแย่งกันกดตอบ
    - แถบเวลา (Timer Bar) เริ่มนับถอยหลังตามเวลาที่ตั้งไว้ (เช่น 10s)
    - ระบบเตือนฉุกเฉิน: เมื่อเวลาเหลือ ≤ 3 วินาที แถบเวลาจะกะพริบแสงสีแดงเตือนเร่งตอบ
    - คำนวณคะแนนตามความเร็ว (Speed-Based Scoring):
      ตอบถูก: คะแนน = คะแนนเต็ม - (Math.floor(เวลาที่ใช้เป็น ms / 500) * 0.5)
      ตอบถูกจะได้คะแนนขั้นต่ำอย่างน้อย 0.5 แต้มเสมอ ส่วนตอบผิดหรือหมดเวลาได้ 0 แต้ม

  ขั้นที่ 4: ช่วงเฉลยคลิปและคำตอบ (Full Reveal Phase)
    - เล่นคลิปเฉลยและเปิดเสียงให้ฟังต่อเนื่อง โดยเลื่อนไปเล่นที่วินาทีเฉลย (Reveal Start Time)
    - แถบเวลานับถอยหลังเปลี่ยนเป็นแถบเขียว "กำลังเล่นคลิปเฉลย 🎬"
    - แถบสถานะด้านบนแสดงชื่อเพลงเฉลยอย่างชัดเจน
    - **ระบบสีของปุ่มช้อยส์ (Refined Reveal Logic)**:
      1. ข้อที่ถูกต้อง (Correct Choice): ไฮไลท์เป็นสีเขียว พร้อมเอฟเฟกต์ Pop เสมอสำหรับทุกคน
      2. ถ้าผู้เล่นเครื่องนี้ "ตอบถูก":
         - ไม่มีปุ่มสีแดงปรากฏเลย
         - ปุ่มตัวเลือกอื่นๆ ที่เหลือจะถูก Dim (ลด Opacity เหลือ 35%) เพื่อขับเน้นข้อที่ถูก
      3. ถ้าผู้เล่นเครื่องนี้ "ตอบผิด":
         - ปุ่มที่ผู้เล่นคนนี้เลือกจะขึ้นเป็น สีแดง (Wrong) ชัดเจน
         - ปุ่มอื่นๆ ที่ไม่ใช่ข้อถูกและไม่ใช่ข้อที่ผู้เล่นเลือก จะถูก Dim (ลด Opacity เหลือ 35%)
      4. มีป้ายชื่อผู้เล่น (Player Badges) ปรากฏใต้ช้อยส์ที่แต่ละคนเลือก

  ขั้นที่ 5: หน้าสรุปคะแนนคั่นระหว่างข้อ (Intermediate Leaderboard with FLIP Animation)
    - เมื่อเล่นคลิปเฉลยจบ (5 วินาที) จะตัดเข้าสู่หน้าตารางคะแนนคั่นข้อ
    - ใช้เทคนิค FLIP Animation (First-Last-Invert-Play) สลับตำแหน่งการ์ดผู้เล่นอย่างนุ่มนวล
      เห็นได้ชัดเจนว่าใครแซงใครขึ้นมาเป็นอันดับ 1
    - แสดงคะแนนที่ได้เพิ่มในข้อนี้ (+X pt) สีเขียวสว่าง
    - โชว์ค้างไว้ 4.5 วินาทีก่อนจะเลื่อนไปยังข้อถัดไปโดยอัตโนมัติ

4. จุดเด่นทางเทคนิคและสถาปัตยกรรม (TECHNICAL HIGHLIGHTS)
--------------------------------------------------------------------------------
1. Serverless P2P WebRTC:
   - สื่อสารระหว่างผู้เล่นด้วย WebRTC DataChannel (PeerJS) ไม่ต้องมี Database หรือ Node.js Server
   - เชื่อมต่อผ่านรหัสห้องสั้น 5 หลัก จำง่าย เข้าเล่นผ่านมือถือได้ทันที
2. Anti-Zombie Peer & Heartbeat Ping/Pong:
   - ยิง Heartbeat ทุก 1.5 วินาที หากหลุดเกิน 5 วินาที ระบบจะ Prune ออกอัตโนมัติ ไม่ให้ห้องค้าง
3. Zero Thumbnail & Title Leak (100% Anti-Spoiler):
   - มี Anti-Spoiler Header Mask ทึบแสงปิดทับส่วนหัวของ YouTube Video ปิดชื่อคลิปและชื่อช่อง 100%
   - หน้าจอนับถอยหลัง 3-2-1 เป็นสีดำสนิท ไร้เงาวิดีโอเล็ดลอด
4. Hybrid Media Engine:
   - โครงสร้างรองรับทั้ง HTML5 <video> ผ่าน Invidious Direct Stream และ Fallback ไปที่ YouTube IFrame
   - จัดการ Player Lifecycle อย่างแม่นยำ ไม่ทำลาย IFrame พร่ำเพรื่อเพื่อความลื่นไหล
5. Automated CI/CD (GitHub Actions):
   - มีสคริปต์ .github/workflows/deploy.yml ทำงานทันทีเมื่อ Push โค้ดเข้า branch main
   - ตรวจสอบโค้ด TypeScript และบิลด์ Vite ขึ้นสู่ GitHub Pages อัตโนมัติ
