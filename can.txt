1. ภาพรวมของโปรเจกต์ (PROJECT OVERVIEW)
--------------------------------------------------------------------------------
GuessThe? คือเว็บแอปพลิเคชันเกมแข่งขัน "ทายเพลง & ทาย MV" แบบ Real-Time Interactive 
สร้างด้วย Vite + TypeScript + Vanilla CSS / Tailwind CSS v4 
รองรับทั้ง:
  1. โหมดเล่นคนเดียว (Singleplayer)
  2. โหมดผู้เล่นหลายคนแบบออนไลน์ (Online Multiplayer สูงสุด 10 คน) ผ่าน WebRTC P2P (PeerJS) 
     โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ฐานข้อมูลส่วนกลาง Host ทำหน้าที่เป็น Game Server แบบกระจายศูนย์

【 หน้า 1: หน้าหลัก (HOME SCREEN) — Route: #/ 】

จุดประสงค์: เลือกระบุชื่อผู้เล่น และเลือกโหมดที่จะเล่น
● เมนูและกล่องข้อมูล:
  1. โลโก้เกม "GuessThe?" พร้อมสโลแกนเกม
  2. ช่อง "ชื่อผู้เล่น" (Input ID: input-player-name)
     - บันทึกชื่อลงใน LocalStorage ให้อัตโนมัติ เล่นครั้งต่อไปไม่ต้องพิมพ์ใหม่
     - รองรับความยาวสูงสุด 20 ตัวอักษร
  3. ป้ายบอกจำนวนเพลงในคลัง (Track Count)
     - แสดงจำนวนเพลงที่มีอยู่ในคลัง เช่น "มี 10 เพลงในคลัง"
     - หากมีน้อยกว่า 4 เพลง จะแจ้งเตือนให้ไปเพิ่มเพลงหรือโหลดเพลงตัวอย่างก่อน

● รายการปุ่มในหน้าแรก:
  [ปุ่ม 1] "🎵 เล่นคนเดียว" (Button ID: btn-solo)
    - วิธีใช้: ใส่ชื่อผู้เล่น แล้วกดปุ่มนี้
    - ผลลัพธ์: พาเข้าหน้า Lobby ในโหมด Solo ทันที
    - เงื่อนไข: ต้องมีเพลงในคลังอย่างน้อย 4 เพลง

  [ปุ่ม 2] "🏠 สร้างห้อง" (Button ID: btn-create-room)
    - วิธีใช้: ใส่ชื่อผู้เล่น แล้วกดปุ่มนี้
    - ผลลัพธ์: สร้างห้อง P2P ขึ้นมา รับหน้าที่เป็น Host และสร้างรหัสตัวเลข 5 หลัก
    - เงื่อนไข: ต้องมีเพลงในคลังอย่างน้อย 4 เพลง

  [กล่อง 3] "🔢 เข้าร่วมห้องด้วยรหัส 5 หลัก"
    - ช่องพิมพ์รหัส: (Input ID: input-room-code) รองรับเฉพาะตัวเลข 0-9 ความยาว 5 หลัก
    - ปุ่ม "🚪 เข้าห้อง" (Button ID: btn-join-room): กดเพื่อเชื่อมต่อ P2P เข้าห้องของเพื่อน

  [ปุ่ม 4] "📋 จัดการคลังเพลง" (Button ID: btn-track-editor)
    - วิธีใช้: กดเพื่อเปิดหน้าจัดการคลังเพลง (Track Editor) สำหรับเพิ่ม/แก้ไข/ลบเพลง

【 หน้า 2: จัดการคลังเพลง (TRACK EDITOR SCREEN) — Route: #/editor 】
================================================================================
จุดประสงค์: เพิ่ม ลบ แก้ไข ฟังตัวอย่างคลิป ปักหมุดวินาที และนำเข้า/ส่งออกเพลง
● เมนูและปุ่มควบคุม:
  [ปุ่ม 1] "←" (ปุ่มย้อนกลับ): กลับสู่หน้าหลัก

  [กล่อง 2] ฟอร์มเพิ่มเพลง / แก้ไขเพลง (Track Form):
    - ช่อง "YouTube ID หรือ ลิงก์คลิป" (Input ID: input-youtube-id):
      รองรับทั้ง URL เต็ม (https://www.youtube.com/watch?v=...), ลิงก์ย่อ (youtu.be), Shorts, หรือ ID 11 หลัก
    - ปุ่ม "🔍 โหลดคลิป & ชื่อเพลง" (Button ID: btn-fetch-title):
      ดึงชื่อเพลงและศิลปินอัตโนมัติผ่าน YouTube oEmbed พร้อมเปิดจอวิดีโอ Preview ขึ้นมาทันที
    - หน้าต่าง "📺 ตัวอย่างคลิป (Preview Player)":
      วิดีโอพรีวิวแบบโต้ตอบได้ มีไทม์ไลน์ให้เลื่อนหาวินาทีที่ต้องการ
      - ปุ่ม "📍 ตั้งเริ่มทาย (Xs)": กดเพื่อดึงวินาทีปัจจุบันของคลิปมาใส่ช่องวินาทีเริ่มทาย
      - ปุ่ม "📍 ตั้งเริ่มเฉลย (Xs)": กดเพื่อดึงวินาทีปัจจุบันของคลิปมาใส่ช่องวินาทีเริ่มเฉลย
    - ช่อง "ชื่อเพลง" (Input ID: input-title): ดึงชื่อเพลงมาให้ สามารถแก้ไขพิมพ์ข้อความเองได้
    - ช่อง "เริ่มที่วินาที (ฟังตอนทาย)" + ปุ่ม "▶️ ฟัง":
      กำหนดวินาทีท่อนที่จะให้ผู้เล่นฟังตอนทาย สามารถกดปุ่ม "▶️ ฟัง" เพื่อทดสอบเล่นคลิปจากวินาทีนั้นได้ทันที
    - ช่อง "เริ่มที่วินาที (ตอนเฉลย)" + ปุ่ม "▶️ ฟัง":
      (ใส่หรือไม่ใส่ก็ได้) กำหนดวินาทีท่อนฮุคที่จะเปิดเฉลยตอนหมดเวลา ถ้าไม่ใส่จะใช้วินาทีทาย
    - กล่องเลือก "ประเภท": เลือกว่าเป็น '🎬 MV Video' (ดูคลิปภาพ) หรือ '🎵 Audio Only' (ฟังแต่เสียง)
    - กล่องเลือก "คะแนน": 10, 15, 20, 25, 30 แต้ม
    - ปุ่ม "➕ เพิ่มเพลง" / "💾 บันทึกการแก้ไข" (Button ID: btn-add-track): บันทึกข้อมูลลง LocalStorage
    - ปุ่ม "✕ ยกเลิกการแก้ไข" (Button ID: btn-cancel-edit): สลับออกจากโหมดแก้ไขกลับเป็นโหมดเพิ่มใหม่

  [แถบ 3] เครื่องมือจัดการชุดข้อมูล (Toolbar):
    - ปุ่ม "นำเข้าไฟล์" (File Input ID: input-import-json): เลือกไฟล์ .json จากเครื่องเพื่อเพิ่มเพลงเข้าคลัง
    - ปุ่ม "วางโค้ด" (Button ID: btn-open-paste-modal): เปิดหน้าต่าง Pop-up ให้วางข้อความ JSON
    - ปุ่ม "Export" (Button ID: btn-export-json): ดาวน์โหลดไฟล์ JSON และเปิด Pop-up ให้กดคัดลอกโค้ด 1-Click
    - ปุ่ม "โหลดเพลงตัวอย่าง" (Button ID: btn-load-samples): โหลดเพลงฮิตไทย 10 เพลงที่มีการตั้งวินาทีทายและเฉลยไว้เป๊ะๆ

  [แถบ 4] ปุ่มปรับประเภทแบบเหมาทั้งหมด (Batch Actions):
    - ปุ่ม "ทาย MV ทั้งหมด": เปลี่ยนทุกเพลงในคลังให้เป็นโหมดดูคลิป MV พร้อมกันในคลิกเดียว
    - ปุ่ม "ทายเพลงทั้งหมด": เปลี่ยนทุกเพลงในคลังให้เป็นโหมดฟังเสียง (Audio Only) พร้อมกันในคลิกเดียว

  [แถบ 5] "🗑️ ลบเพลงทั้งหมด" (Button ID: btn-clear-all):
    มีระบบป้องกันการกดพลาด แสดงปุ่มยืนยัน "ลบเลย!" และ "ยกเลิก"

  [แถบ 6] รายการเพลงทั้งหมด (Track List):
    แสดงรายการเพลงทั้งหมด แต่ละเพลงมีปุ่มจัดการ 3 ปุ่ม:
    - ปุ่ม "▶️" (พรีวิว): โหลดเพลงขึ้นจอ Preview ด้านบนทันที
    - ปุ่ม "✏️" (แก้ไข): นำข้อมูลเพลงขึ้นไปกรอกในฟอร์มด้านบนเพื่อแก้ไข
    - ปุ่ม "🗑️" (ลบ): ลบเพลงนั้นออกจากคลังทันที

【 หน้า 3: หน้าห้องรอ (LOBBY SCREEN) — Route: #/lobby 】
================================================================================
จุดประสงค์: เตรียมความพร้อมของผู้เล่น และตั้งค่ากฎการแข่งขัน
● เมนูและกล่องข้อมูล:
  1. ปุ่ม "← กลับหน้าหลัก": ตัดการเชื่อมต่อและกลับสู่หน้าแรก
  2. กล่องแสดงรหัสห้อง (สำหรับ Host):
     - แสดงรหัสตัวเลข 5 หลักขนาดใหญ่ สามารถ "แตะ/คลิก เพื่อคัดลอก" ได้ทันที
  3. รายชื่อผู้เล่นในห้อง (Players Grid):
     - รองรับผู้เล่น 1 ถึง 10 คน
     - แสดงชื่อ, Avatar สีประจำตัว, ป้าย "👑 Host", และสถานะ "● Online"
     - หากเป็น Host จะมีกล่องขอบประ "⏳ รอผู้เล่นเข้าร่วม (X/10)..."
  4. แผงตั้งค่าเกม (⚙️ ตั้งค่าเกม — ปรับได้เฉพาะ Host และ Solo):
     - [เมนูย่อย 1] "จำนวนข้อ": เลือก 'ทั้งหมด (ตามคลังเพลง)', 5 ข้อ, 10 ข้อ, 15 ข้อ, 20 ข้อ
     - [เมนูย่อย 2] "เวลาแสดงเพลงทาย": 1s, 2s, 3s (มาตรฐาน), 5s, 8s, 10s (ระยะเวลาของท่อนเพลง)
     - [เมนูย่อย 3] "เวลาจับเวลาตอบ": 5s, 10s (มาตรฐาน), 15s, 20s, 30s (เวลาที่นับถอยหลังให้กดช้อยส์)
     - [เมนูย่อย 4] "เวลาแสดงตอนเฉลย": 3s, 5s (มาตรฐาน), 7s, 10s, 15s (ระยะเวลาเปิดเฉลยให้ฟังเพลงต่อ)

● ปุ่มในหน้า Lobby:
  [ปุ่ม 1] "🎮 เริ่มเกม!" (Button ID: btn-start-game):
    - สำหรับ Host หรือ Solo: เริ่มเกมทันที ระบบจะสุ่มเพลงและช้อยส์ แล้วส่งข้อมูล синхronize ไปยังเครื่อง Client ทุกคน
    - สำหรับ Client: จะขึ้นข้อความ "รอ Host เริ่มเกม..." พร้อมไอคอนโหลด

【 หน้า 4: หน้าเล่นเกม (GAME SCREEN) — Route: #/game 】
================================================================================
จุดประสงค์: หน้าจอหลักขณะกำลังเล่นเกม ทายเพลง และดูเฉลย
● การไหลของรอบเกม (Two-Stage Gameplay Flow):
  ขั้นที่ 0: กำลังเตรียมเพลง (Prebuffer Phase)
    - ตัวเล่น YouTube โหลดและเลื่อนไปยังวินาทีที่ตั้งไว้ โดยมีระบบ Timeout 5 วินาที
    - หากคลิปมีปัญหาหรือติดลิขสิทธิ์ จะข้ามอัตโนมัติเพื่อให้เกมดำเนินต่อได้ทันที
    - มีหน้าจอนับถอยหลัง 3... 2... 1... กลางจอ

  ขั้นที่ 1: ช่วงเล่นเพลงทาย (Snippet Playing Phase)
    - ตัวเล่นเริ่มเล่นเพลงตามเวลา "เวลาแสดงเพลงทาย" ที่ตั้งไว้ (เช่น 3 วินาที)
    - โหมด MV Video: เปิดคลิปให้เห็นภาพ
    - โหมด Audio Only: มีม่านดำทึบ 100% ปิดมิดชิด ป้องกัน Thumbnail หลุด พร้อมแสดง Visualizer คลื่นเสียง
    - ด้านบนของวิดีโอมี Anti-Spoiler Mask ปิดชื่อคลิปและชื่อช่องของ YouTube เสมอ
    - **สำคัญ**: ในขั้นตอนนี้ ปุ่มช้อยส์ทั้ง 4 ข้อจะถูกล็อค (Disabled, Opacity 60%, ห้ามกด) เพื่อความยุติธรรม

  ขั้นที่ 2: ช่วงจับเวลาตอบ (Answering Countdown Phase)
    - เมื่อเพลงท่อนตัวอย่างเล่นจบ วิดีโอจะถูกคลุมม่านดำทันที (กันจอค้างสปอยล์ชื่อ)
    - ปุ่มช้อยส์ 4 ตัวเลือก ปลดล็อคพร้อมกัน ให้ผู้เล่นสามารถคลิกตอบได้
    - แถบเวลาตอบ (Answer Timer Bar) เริ่มนับถอยหลัง
    - ระบบแจ้งเตือนฉุกเฉิน (Urgency Effects): เมื่อเวลาเหลือน้อยกว่าหรือเท่ากับ 3 วินาที
      แถบเวลาจะกลายเป็นสีส้มแดงนีออนกะพริบเร็ว และไอคอนจะเปลี่ยนเป็น 🚨 เตือนให้รีบตอบ

  ขั้นที่ 3: ช่วงเฉลยคำตอบ (Reveal Phase)
    - เมื่อผู้เล่นทุกคนตอบครบ หรือเวลาตอบหมดลง:
    - ตัวเล่นเปิดเฉลยเพลง พร้อมเลื่อนไปเล่นที่วินาทีเฉลย (Reveal Start Time)
    - ปุ่มคำตอบที่ถูกต้องจะเปลี่ยนเป็นสีเขียว (Correct)
    - ปุ่มคำตอบที่ตอบผิดจะเปลี่ยนเป็นสีแดง (Wrong)
    - แสดงป้ายชื่อผู้เล่น (Player Badges) ใต้ช้อยส์ที่ตนเองเลือก
    - อัปเดตคะแนนบนกระดานคะแนนด้านบนแบบ Real-Time
    - เมื่อครบเวลาเฉลย จะข้ามไปยังข้อถัดไปอัตโนมัติ

● กติกาการคิดคะแนนตามความเร็ว (Speed-Based Scoring System):
  - ตอบถูก: คะแนน = คะแนนเต็มของข้อนั้น - คะแนนที่ถูกหักตามเวลา
  - อัตราการหักคะแนน: ทุกๆ 500 มิลลิวินาที (0.5 วินาที) ที่ผ่านไป จะหัก 0.5 แต้ม
    สูตร: Math.floor(timeUsedMs / 500) * 0.5
  - ป้องกันคะแนนติดลบ: ตอบถูกจะได้คะแนนขั้นต่ำอย่างน้อย 0.5 แต้มเสมอ
  - ตอบผิด หรือตอบไม่ทัน (หมดเวลา 0s): ได้ 0 แต้ม

4. ฟีเจอร์เด่นด้านเทคนิคและเครือข่าย (TECHNICAL HIGHLIGHTS)
--------------------------------------------------------------------------------
1. Serverless P2P WebRTC:
   - ใช้ PeerJS เชื่อมต่อเครื่องผู้เล่นเข้ากับ Host โดยตรง ไม่ต้องมีเซิร์ฟเวอร์ฐานข้อมูล
   - รหัสห้องเป็นตัวเลข 5 หลัก สั้น จำง่าย พิมพ์สะดวกบนมือถือ
2. Heartbeat & Auto-Pruning:
   - ตรวจจับ Ping/Pong ทุกๆ 1.5 วินาที
   - หากผู้เล่นคนใดเน็ตหลุดหรือปิดแท็บเกิน 5 วินาที ระบบจะตัดออกจากห้องอัตโนมัติ เพื่อไม่ให้เพื่อนคนอื่นติดค้างที่หน้าตอบ
3. Zero Thumbnail Bleed & Anti-Spoiler:
   - ในโหมดทายเพลง (Audio Only) หน้าจอวิดีโอจะถูกปรับ Opacity เป็น 0 และถูกปิดทับด้วยม่านสีดำทึบ 100% 
   - ป้องกันภาพปกคลิปของ YouTube รั่วไหลก่อนเฉลยอย่างเด็ดขาด
4. Responsive & PWA-Ready:
   - ออกแบบ UI แบบ Glassmorphism ที่สวยงาม ดูโมเดิร์น ใช้งานง่ายทั้งบนคอมพิวเตอร์และมือถือสมาร์ตโฟน
